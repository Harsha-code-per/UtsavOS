# Security

## Reporting

Please report vulnerabilities privately to harshavardhan3259@gmail.com rather than opening a public issue.

## Threat model and controls

| Threat                                  | Control                                                                                                                                                                                                                                                                                                       | Where                                                                                                              |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Leaked AI credentials                   | `GEMINI_API_KEY` is read only in server route handlers and never sent to the browser. `.env*` is git-ignored and `.env.example` holds no values.                                                                                                                                                              | [`planner.ts`](src/lib/ai/planner.ts)                                                                              |
| Cross-site scripting                    | A per-request nonce CSP with `strict-dynamic` and no `unsafe-inline` or `unsafe-eval` in production. React escapes all rendered text. The UI has no inline `style` attributes, so the CSP needs no style exemption.                                                                                           | [`proxy.ts`](src/proxy.ts), [`csp.ts`](src/lib/security/csp.ts)                                                    |
| Clickjacking, sniffing, downgrade       | `frame-ancestors 'none'`, `X-Frame-Options: DENY`, `nosniff`, HSTS with preload, `upgrade-insecure-requests`, a strict `Referrer-Policy` and a minimal `Permissions-Policy` (microphone is same-origin only, for voice input)                                                                                 | [`next.config.ts`](next.config.ts)                                                                                 |
| Malformed or oversized requests         | Every API route requires JSON, caps the body size, and validates with zod before any work. Errors name the field, never internals.                                                                                                                                                                            | [`http.ts`](src/lib/api/http.ts)                                                                                   |
| Abuse and quota exhaustion              | Per-client fixed-window rate limits on every AI route, plus a 30-minute cache for identical requests                                                                                                                                                                                                          | [`rate-limit.ts`](src/lib/security/rate-limit.ts), [`cache.ts`](src/lib/api/cache.ts)                              |
| Prompt injection                        | User text is placed inside tagged data blocks with `<` escaped, so it can't close the block. System prompts say to treat tagged content as data only. Output must match a schema. Tool calls are allow-listed, re-validated, checked against the actual plan, and **only applied after the person approves**. | [`prompts.ts`](src/lib/ai/prompts.ts), [`tools.ts`](src/lib/ai/tools.ts), [`/api/chat`](src/app/api/chat/route.ts) |
| Untrusted model output                  | `sanitizeDraft` keeps only items that validate, and `applyChange` re-validates the whole plan after every edit, so no output can produce an inconsistent plan                                                                                                                                                 | [`plan.ts`](src/lib/domain/plan.ts)                                                                                |
| Reading or writing other people's plans | Firestore rules allow access to `users/{uid}/plans/*` only for that `uid`, enforce the exact document shape and limits, and deny everything else. Covered by emulator tests.                                                                                                                                  | [`firestore.rules`](firestore.rules), [`rules/firestore.test.ts`](rules/firestore.test.ts)                         |
| Tampered local storage                  | Plans read from `localStorage` are validated with zod. Invalid entries are ignored.                                                                                                                                                                                                                           | [`local.ts`](src/lib/store/local.ts)                                                                               |
| Private data in URLs                    | The landing description reaches the wizard through `sessionStorage`, never the query string                                                                                                                                                                                                                   | [`handoff.ts`](src/lib/store/handoff.ts)                                                                           |
| Vulnerable dependencies                 | CI runs `npm audit --omit=dev --audit-level=high` (currently 0 vulnerabilities). Firebase's transitive `@grpc/grpc-js` is pinned to a patched release through `overrides`.                                                                                                                                    | [`ci.yml`](.github/workflows/ci.yml), [`package.json`](package.json)                                               |

## Notes

- The Firebase web config (`NEXT_PUBLIC_FIREBASE_*`) is public by design. Access control is enforced by the security rules, not by keeping those values secret.
- Rate limiting reads the first `X-Forwarded-For` address. Vercel overwrites this header with the real client address, so clients cannot spoof it in production. Limits are kept in memory per serverless instance; a shared store would be the next step if abuse ever required it.
- `npm audit` without `--omit=dev` reports a `braces` advisory inside the ESLint plugin used by `eslint-config-next`. It runs only on developer machines and in CI linting, never in the deployed app, and no patched release exists yet.
